-- O6b: serving SLO
target: p99 <= 100 ms
This target is ours and self-imposed. No SLA was ever published upstream, so
rather than leave the serving latency unstated we set a number and measure it.

measured server-side from system.query_log.query_duration_ms, looked up by
query_id. Not client wall clock: network round trip and Python overhead are
excluded, so this is what the server itself spent.

samples: 40 of 40 (8 benchmark queries x 5 repetitions)
min       83.0 ms
p50       91.0 ms
p95      110.0 ms
p99      127.0 ms
max      127.0 ms

FAIL: measured p99 of 127.0 ms is over the 100 ms target

percentiles are nearest-rank over every sample. The per-sample rows are in
evidence/serving_slo.csv so these numbers can be recomputed, not just believed.
